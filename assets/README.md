# Local character assets

Character assets are deliberately not distributed with MotionViewer. Place locally licensed binary FBX files under `assets/fbx/` and keep their `catalog.json` beside them. PMX files and SMPL-X model weights must remain local.

Several assets used during development explicitly prohibit redistribution. The repository ignore rules therefore exclude everything below `assets/` except this notice.

See `docs/assets.md` for catalog fields and validation commands.
