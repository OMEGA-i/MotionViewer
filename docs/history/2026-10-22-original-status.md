## 二、这段时间解决掉的问题

| 问题 | 怎么解决的 |
|---|---|
| **腿穿裙子** | 用 PMX 自带的刚体和关节跑 Bullet（`--bullet`）。穿模顶点从 3.1% / 2.9% 降到 **0%** |
| **布料乱抖、裙摆被甩飞** | 三个单位错误：① MMD 的阻尼和 Blender 的**定义相反**（0.9999 在 MMD 是"几乎不衰减"，在 Blender 是"几乎全扣掉"），mmd_tools 直接照抄；② 重力要用 MMD 的 −7.848 而不是 −9.81；③ Bullet 的步长取自场景帧率，而场景一直是 Blender 默认的 24，动作是 50 fps |
| **脚在地上滑** | 根位移的缩放要按**腿长**而不是身高。宵宫腿/身高是 0.4592，源骨架是 0.5322，按身高算多走 15.9%，每走一米planted的脚滑 15.9 cm |
| **8 个角色渲出来一片洋红** | 文件名编码。两个方向的乱码都有：GBK 当成 CP932 读（`颜`→`ﾑﾕ`），和 Shift-JIS 当成 GBK 读（`体`→`懱`）。贴图按 PMX 自己的贴图清单对照改名 |
| **手插进头发/帽子** | `--head-clear`，只转肩关节，其他关节位移 0.000000 mm。默认关闭，因为它改动了动作 |
| **判断一个角色能不能用** | 测**绑定姿势到站立姿势的增量**，不是测站立本身 —— 手套和袖口本来就包住手指，两个姿势都包，所以抵消掉了 |
| **握剑：剑柄在手背上 / 手指全部变形** | 见下节，这个来回最多 |
| **仓库 3.9 G** | 清到 1.6 G。能重跑出来的渲染帧都删了，测量数据和手工挑选的东西留下并归档 |

### 握剑这件事，为什么来回这么多次

最后定位到的根因是：**我搜索手指弯曲角度时上限设成 140°，这个数字没有任何依据**。
三节指骨按 (1.0, 1.25, 0.85) 的比例，136° 的掌指角对应中节 **170°** —— 手指直接折穿自己。

真实关节极限是掌指 90° / 中节 110° / 末节 90°，反算出掌指上限 **88°**。改成按解剖极限截断后，四个角色全落在 48–88°，变形消失。彦卿之前"看着还行"纯属它碰巧解在 88°。

另外测出来这些手全握时只能围成**半径约 10 mm 的环**（约 20 mm 杆径），所以超出的半宽要从掌心法向推出去，让手指能碰到杆面而不是要求关节超限。

## 三、还没解决 / 你可能想先知道的

1. **批量脚本还没接上物理。** `visualize_dataset.py` 仍然在传 `--spring`（弹簧近似），没传 `--bullet`。
   `converted/final/` 里的视频都是我直接调 `render_mmd_compare.py` 渲的。
   **要批量出论文视频的话，这个得先接上**，否则 400 条都是旧的布料效果。

2. **飞霄握不住武器。** 它的杆 37 mm，手全握只能围 20 mm，食指和小指差 21–24 mm，拳头在杆旁边而不是围住它。没出成品视频。要么换一个"张开一点"的手型，要么承认这把武器对这只手太粗。

3. **所有握持都没用拇指。** 拇指反方向包，用同一套弯曲会让它穿过握把。

4. **`skirt_physics.json` 的 `lower_share` 那一列不能信。** 它按模型局部 Z 选"裙子顶点"，但这些模型的 `センター` 在大腿中部不在腰，所以选中的其实是小腿和脚。重测的办法是用模型自己的 `裙_*` 骨骼（宵宫 96 根，流萤 112 根）。`mesh_share` 那列是对的。

5. **地面接触是按静止姿势算的。** 角色实际悬空 4–8 cm，渲染时靠把地板道具降下来遮掉了。只要有东西假设地面在 Z=0（物理道具、反射面、接触检测），就会差这么多。

6. **私有仓库是旧的。** `poisonousID/blender` 是在握持和物理那批修复**之前**推的，而且现在没配成 remote。`origin`（`OMEGA-i/MotionViewer`）这个分支落后本地 16 个提交。要我推就说一声。

7. 脸部阴影还是压平的渐变，不是游戏那种 SDF 贴图。

## 四、已经放弃 / 别再试的方向

提醒你一下，这些每个都花过时间，而且**全都是"输出看起来挺像那么回事，其实是错的"**，不是报错。

| 放弃的 | 为什么 |
|---|---|
| 弹簧解算器里加重力 | 模型的静止姿势**本身就是**垂下来的姿势，重力已经在里面了，再加就把每根骨头拖到角度上限 |
| `foot_lock` 脚部锁定模块 | 建立在我判断错的前提上 —— 脚滑是位移缩放用了身高，不是真的滑。写完了，你让删，删了 |
| 布料跟随度相关性指标 | 完全看不出问题。被拉变形的裙片和正常的裙片都是滞后 1 帧、r=0.80 —— 错的是形状不是时序 |
| 用"根骨骼以下最宽处"量裙摆 | 量的其实是跨步宽度。所以才会得出"阻尼越大裙摆越宽 32%"这种不可能的结论 |
| 用"到杆轴的距离"判断握持 | 轴是一条无限长的直线，离它 13.6 mm，手心一侧和手背一侧都满足。这是第三次指标量错了对象 |
| 直接统计"手指被包住的比例" | 宵宫被判 26.8%、30.2%，而它从来没穿模过。袖口和手套本来就包手指 |
| 拿手部顶点去射"其他 mesh 物体" | 这些模型是**单个** mesh 带二十来个材质，没有"其他物体"可以射。19 个角色全报 0.0% |
| 用"占主导的顶点组"识别部位 | `mmd_edge_scale` 在**每个**顶点上权重都是 1.0，两次探测都被它废掉 |
| 按"字符合理性"给贴图改名打分 | 试了两次都不行。要按 PMX 自己的贴图清单对照 |
| 武器对齐用固定欧拉角 | MMD 各家骨骼 roll 不统一，−95° 让球拍竖着而手臂朝下 |
| 用几何规则判断武器哪头是握把 | 三套规则各自都是 4 个对 3 个。所以现在是一张写死的表 `WEAPON_BY_CHARACTER` |
| 整条手臂重建 FK 来躲头 | 最小二乘出来的静止偏移残差 12–57 mm。改成整条手臂刚性旋转就是精确的 |
| **搬纸箱（016783）** | 几何死结：那条动作手在 1.28 m，箱子放在手上箱顶就到 1.59 m，而脸在 1.55 m，必然挡脸。你最后说"木箱不管了" |
| 手指弯曲搜到 140° | 没有依据的上限，就是手指变形的根因（见上一节） |
